Google Sheet Sync

Connect this map to a Google Sheet so every job you add saves to the sheet automatically and syncs across devices.

Paste the URL you got after deploying the Apps Script (step 5 below).
One-time setup (5 minutes)
  1. Open sheets.new to make a fresh Google Sheet. Name it whatever you like (e.g. "Job Map").
  2. In the sheet, click Extensions → Apps Script. A code editor opens in a new tab.
  3. Delete whatever code is there. Click Copy script below, then paste it into the editor.
  4. Click the 💾 save icon (or Ctrl/Cmd+S). Name the project anything.
  5. Click Deploy → New deployment (top right). Click the gear icon ⚙ next to "Select type" → choose Web app. Set:
    • Execute as: Me
    • Who has access: Anyone
    Click Deploy. Google will ask you to authorize — click through (you may need to click "Advanced → Go to project (unsafe)" — it's safe, it's your own script).
  6. Copy the Web app URL Google gives you (ends in /exec) and paste it in the field above. Click Save & Sync.

⚠️ Anyone with that URL can read/write your sheet. Don't share it publicly. For a personal job tracker this is fine.
